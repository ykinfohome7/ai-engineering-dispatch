# Support and questions

> 🇧🇬 Приемаме въпроси на български или английски.

## Questions and bug reports

> 🇧🇬 Публикувайте въпрос или доклад за грешка в GitHub Issues.

Use the [GitHub Issue templates](https://github.com/ykinfohome7/ai-engineering-dispatch/issues/new/choose) for questions, defects and feature ideas. Share version, environment and reproducible steps, but never include secrets, private server addresses, credentials or customer information. Both BG and EN are accepted.

## Vulnerability reports

> 🇧🇬 Уязвимостите се съобщават поверително.

Follow [SECURITY.md](SECURITY.md), not a public Issue, for security vulnerabilities. Report Paperclip-specific upstream issues to [Paperclip](https://github.com/paperclipai/paperclip/issues).

## Availability

> 🇧🇬 Проектът е в разработка и няма гарантиран SLA.

This open-source project is best-effort. A support Issue does not imply a production support contract or 24/7 response.
