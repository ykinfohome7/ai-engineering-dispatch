# ai-engineering-dispatch
BGDB AI-EMDS — AI Engineering Management &amp; Dispatch System. ChatGPT takes in tasks, Paperclip dispatches them to AI agents (Claude Code, Codex). Runs in GitHub Codespaces first, then on a self-hosted Proxmox server. Agent roles: Architect, Developer, Reviewer, QA, DevOps, Docs. Secure access via Tailscale and KSSH.
